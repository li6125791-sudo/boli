# Boli 账本

美元 (USD) / 坚戈 (KZT) / 人民币 (CNY) 三币种进出账系统，单文件网页应用：`index.html`。

- 进账、出账、换汇三种记录；每笔保存当时的 USD/CNY、USD/KZT 汇率，自动算交叉汇率和折合金额
- 手续费、待收/待付（应收应付）、单号、备注
- 概览：进账、出账、净利润、利润率、汇兑损益、月度图表、各币种余额、客户利润排行、支出构成
- 流水：按期间、类型、币种、客户、类别、状态筛选和搜索，导出 CSV / 备份 JSON
- 客户：每个客户的进账、出账、利润、利润率、待收
- 汇率：默认汇率设置、交叉汇率表、换算器
- 统计可以按人民币、美元、坚戈任一币种折算显示

直接用浏览器打开 `index.html` 即可使用（数据保存在本机浏览器）；发布为 Claude Artifact 时数据保存在云端。
